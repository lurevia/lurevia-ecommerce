# Migration des chemins

Les fichiers ont été déplacés pour suivre l'arborescence du module `addresses`. Les imports **à l'intérieur** de `modules/` sont déjà mis à jour ; les imports **depuis l'extérieur** (routeur principal, `server.ts`, tests...) sont à adapter, de préférence vers `modules/<nom>/index.ts`.

## Changements de symboles

| Avant | Après |
|---|---|
| `toXxxDto(x)` / `items.map(toXxxDto)` | `xxxMapper.toOutput(x)` / `xxxMapper.toOutputList(items)` |
| `bidsMapper.toDto(x)` | `bidsMapper.toOutput(x)` |
| `notificationsService.notifyXxx(...)` | `notificationTriggersService.notifyXxx(...)` |
| `export const xService = { ... }` | `export class XService { ... }` + `export const xService = new XService(repo)` |
| `adminService` re-exportant `adminVerificationService` / `adminIdentityService` | import direct depuis `services/admin-verifications.service` et `services/admin-identity.service` |
